# The Reading Room

An editorial research interface, built around reading rather than dashboard metrics.

- White canvas, near-black text, cobalt-blue annotations, fine rules, and square controls.
- Serif reading typography with italic emphasis; sans-serif navigation and monospace provenance.
- A horizontal directory separates Reading room, Collection, Atlas, and Notebook. The document library has its own indexed list instead of a persistent sidebar.
- An answer is laid out as an article. Its source passages appear in the margin with reference IDs, locations, retrieval channels, and expandable full text.
- On narrow screens, the answer and its references form one reading column. Dense atlas diagrams pan within their own region without widening the page.
- Keyboard focus remains visible; file import uses a native button; status announcements and skip navigation support keyboard and assistive navigation.

No external fonts or image assets are required. The UI uses the existing document, retrieval, graph, and history services. Screenshots use the fictional Atlas collection in offline extractive mode.
